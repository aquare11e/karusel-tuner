- [x] Лимит одновременно запущенных Streamlink-процессов и HTTP 503 при перегрузке.
- [x] Таймаут запуска до первых байт, HTTP 502 при недоступном источнике.
- [x] Завершать всю группу дочерних процессов на таймауте/отключении/выходе.
- [x] Unit/HTTP tests с мок-CLI, `go test -race` без VPN.
- [x] Конфиг Docker Compose с Gluetun и локальным bind relay на loopback.
- [x] ~~Opt-in Threadfin профиль~~ — заменён встроенным тюнером HDHomeRun и XMLTV (`/epg.xml`); Threadfin удалён.
- [x] Локальный стенд с Plex (`compose.local-plex.yaml`, `make local-up`).
- [ ] Проверить реальную VPN-сессию на машине владельца и зафиксировать особенности профиля (НЕ коммитить профиль!). Acceptance: VPN соединяется, `streamlink --stream-url` возвращает HLS, на хосте видео декодируется `ffprobe`.
- [ ] End-to-end проверить канал в Plex через встроенный тюнер. Acceptance: Plex добавляет тюнер по адресу, гид из `/epg.xml` с верным временем, запись «Спокойной ночи, малыши!» в 21:00 МСК проходит (не заставка), остановка не оставляет процессов.
- [ ] Добавить e2e-test в отдельном окружении Docker без настоящего VPN через синтетический MPEG-TS источник; CI не должен использовать секреты.

## P1 — устойчивость 24/7

- [ ] Readiness мониторинг VPN и upstream **без** запуска бесконечного просмотра и без утечки секретов. `/healthz` оставить liveness. Acceptance: `/readyz` документирует отдельно состояние VPN, поток и причины отказа.
- [ ] Structured logging/metrics: startup latency, причины обрыва, качество, active viewers; запрет логирования токенов и VPN-учётных данных. Acceptance: количественные показатели тестируются.
- [ ] Shared upstream, fan-out MPEG-TS на нескольких подписчиков с bounded memory и backpressure. Acceptance: один Streamlink при 2+ клиентах, медленный клиент не блокирует остальных, idle отключает upstream.
- [x] Автовосстановление потока внутри ответа: перезапуск Streamlink с растущей паузой, окно `RECONNECT_WINDOW`, тесты на обрывы. Без jitter (один источник, один клиент).
- [ ] Поддержка выравнивания/ремультиплексирования FFmpeg при несовместимом TS без лишнего транскодирования. Acceptance: ffprobe видит video/audio, базовый профиль Plex воспроизводит поток.

## P2 — удобство и качество

- [ ] Убрать зависимость от статичного MediaVitrina iframe ID: проверять официальный URL, находить текущий плеер легальными способами. Не обходить DRM, подписи, paywall и условия доступа. Acceptance: обновление источника без ручных изменений `SOURCE_URL` при разрешённом источнике.
- [x] XMLTV из расписания karusel-tv.ru, время с `+0300`, ежедневные выпуски как серии с датой.
- [ ] Вырезать query-параметры (токены) из URL в выводе Streamlink, который попадает в лог relay.
- [ ] Нижняя граница для `EPG_REFRESH` (например, 15m).
- [ ] Необязательный systemd unit для Compose или инструкция Docker restart policy, обновление, backup/restore `.env` и VPN-профиля.
- [ ] CI security/format checks, закреплённые версии Docker images и воспроизводимость сборок.
